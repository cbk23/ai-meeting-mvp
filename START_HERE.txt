🚀 QUICKEST PATH TO LIVE APP (15 MINUTES)
================================================================================

STEP 1: Get Gemini API Key (2 minutes)
────────────────────────────────────
1. Visit: https://ai.google.dev
2. Click: "Get API Key"
3. Follow the prompts
4. Copy your API key
5. Save it somewhere safe

STEP 2: Deploy to Railway (10 minutes)
──────────────────────────────────────
1. Go to: https://railway.app
2. Sign up: With GitHub (easiest)
3. Click: "Create New Project"
4. Select: "Deploy from GitHub"
5. Choose: Your ai-meeting-mvp repo
6. Add variable: GEMINI_API_KEY = your-key-from-step-1
7. Click: Deploy
8. Wait: ~2-3 minutes

STEP 3: Test (3 minutes)
────────────────────────
1. Copy the live URL from Railway
2. Open it in your browser
3. Paste a sample transcript
4. Click "Generate AI Notes"
5. See AI-generated summary! ✅

RESULT: Your app is live online 🎉
